# Aisha — Romantic Birthday Site

This repository contains a personalized birthday website for Aisha. The site is built with Vite and plain HTML/CSS/JS with optional React components.

Quick commands
- Install dependencies: `npm install`
- Run dev server: `npm run dev`
- Build for production: `npm run build`

Deployment
- Vercel: `vercel` will detect Vite and use `npm run build` to produce the `dist` output directory. See `vercel.json` for build settings.

Notes
- Do not commit `node_modules` or build artifacts. A `.gitignore` is included.
